# VictusControl

Легковесная альтернатива OMEN Gaming Hub для переключения режимов питания и лимитов видеокарты (TGP и Dynamic Boost) на ноутбуках HP Victus и OMEN через WMI ACPI.

[![Build](https://github.com/hexdm09/VictusControl/actions/workflows/build.yml/badge.svg)](https://github.com/hexdm09/VictusControl/actions/workflows/build.yml)
[![Release](https://img.shields.io/github/v/release/hexdm09/VictusControl)](https://github.com/hexdm09/VictusControl/releases)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

> Статус: версия v0.0.1-alpha. Поддерживает Windows 10/11 x64 с включенной изоляцией ядра (HVCI). Протестировано на HP Victus 16-s1xxx с NVIDIA GeForce RTX 4070 Laptop.

## Зачем это сделано

На игровых ноутбуках HP максимальная мощность железа ограничена прошивкой. Если в фирменном OMEN Gaming Hub не включен режим высокой производительности, видеокарта сидит на базовом TGP (около 60-80 Вт вместо паспортных 115-140 Вт у мобильной RTX 4070), а Dynamic Boost отключен.

Сам OMEN Gaming Hub при этом представляет собой громоздкий софт:
- Потребляет от 300 до 600 МБ оперативной памяти.
- Держит в системе до пяти фоновых служб (HP App Helper, HP Omen Cap, HP Network Optimizer и другие).
- Постоянно собирает и отправляет аналитику.
- Долго стартует и перегружен магазином игр и вкладками сообществ.

В реальности от этого софта нужны только три вещи: переключение профилей питания, управление лимитом видеокарты и рабочая клавиша `Fn+P`.

VictusControl решает эту задачу точечно. Утилита взаимодействует с BIOS напрямую через системный интерфейс WMI, не требует установки рантаймов, расходует около 60 МБ памяти (self-contained .NET 9) и полностью исключает сетевую активность.

## Сравнение с OMEN Gaming Hub

| Параметр | OMEN Gaming Hub | VictusControl |
|---|---|
| Потребление памяти | 300-600 МБ | ~60 МБ (self-contained .NET 9) |
| Нагрузка на CPU в фоне | 0.5-3% | 0.0% |
| Фоновые службы Windows | 4-6 служб | 0 служб (один процесс в трее) |
| Сетевая активность | Регулярная телеметрия | Отсутствует полностью |
| Время переключения режима | 1-2 секунды | Около 50 мс |
| Работа с изоляцией ядра (HVCI) | Да | Да (нативный WMI/CIM) |
| Вес дистрибутива | > 500 МБ | ~68 МБ CLI / ~108 МБ приложение (self-contained; exe + один нативный dll) |

## Возможности

- **Полноценное окно приложения**: тёмный интерфейс с карточками профилей, живыми показаниями датчиков (CPU/GPU температура, обороты обоих вентиляторов) и настройками. Кнопка закрытия сворачивает окно в трей (настраивается), полный выход — через меню трея.
- **Три фиксированных профиля**:
  - **Eco (Тихий)**: пониженные обороты вентиляторов, cTGP выключен, Dynamic Boost выключен.
  - **Balanced (Стандартный)**: умеренный шум, cTGP выключен, Dynamic Boost включен.
  - **Performance (Производительный)**: максимальные обороты обдува, полный cTGP и Dynamic Boost (до 140 Вт на RTX 4070).
- **Управление вентиляторами**: авто-кривая прошивки, максимум (100%) или ручной процент 1–100 для обоих вентиляторов (WMI-субкоманда `0x2E`, формат OmenMon).
- **System Vitals в реальном времени**: температура CPU и GPU, обороты вентиляторов обновляются каждые 2 секунды, пока окно открыто; в свёрнутом виде опрос останавливается (0% CPU).
- **Два формата работы**:
  - Автономный консольный клиент `VictusControl.exe` для автоматизации и скриптов.
  - Приложение `VictusControlTray.exe`: окно + иконка в трее с цветовой индикацией активного режима.
- **Поддержка аппаратных клавиш**:
  - Перехват аппаратного сочетания `Fn+P` и кнопки OMEN через системные события WMI.
  - Резервный глобальный хоткей `Ctrl+Shift+P`.
- **Экранный индикатор (OSD)**:
  - Компактное уведомление вверху экрана при смене профиля.
  - Не забирает фокус ввода и не сворачивает полноэкранные игры.
- **Сторожевой таймер прошивки (Watchdog)**:
  - Автоматическое подтверждение режима каждые 75 секунд для защиты от скрытого сброса оборотов кулеров контроллером EC.
- **Умный автозапуск**:
  - Регистрация в планировщике задач Windows с повышенными привилегиями без постоянных окон UAC.
  - Патч XML-манифеста задачи для предотвращения отключения при старте ноутбука от аккумулятора.
  - Опция «стартовать свёрнутым в трей».
- **Настройки сохраняются** в `%LocalAppData%\VictusControl\settings.json` (OSD, watchdog, поведение окна, позиция окна).

## Поддерживаемое железо

- Ноутбуки HP Victus 15 / 16 (ревизии 2022 года и новее).
- Ноутбуки HP OMEN 16 / 17.
- Видеокарты NVIDIA GeForce RTX 30-й и 40-й серий.
- Процессоры AMD Ryzen и Intel Core.
- Операционная система: Windows 10 x64 / Windows 11 x64.

Приложение само определяет возможности платы при старте (термополитика, GPU power, вентиляторы, температуры, переключатель графики) и скрывает неподдерживаемые функции — разные ревизии OMEN/Victus работают без ручной настройки. Диагностика платы: `VictusControl.exe --info`. Неигровые линейки HP (Pavilion, Envy, Spectre, EliteBook) не поддерживаются — в их прошивке нет интерфейса `hpqBIntM`.

## Быстрый старт

### Вариант 1. Готовые файлы из релиза

1. Перейдите на страницу [Releases](https://github.com/hexdm09/VictusControl/releases) и скачайте архив `VictusControl-v0.0.1-alpha.zip`.
2. Распакуйте архив в удобную папку (например, `C:\Tools\VictusControl`).
3. Запустите `VictusControlTray.exe` от имени администратора.
4. В разделе Settings главного окна включите «Start with Windows».

### Вариант 2. Быстрая сборка через install.bat

Если на компьютере установлен .NET SDK 9:

```cmd
git clone https://github.com/hexdm09/VictusControl.git
cd VictusControl
install.bat
```

Скрипт прогонит тесты, соберет исполняемые файлы в папку `dist/` и проверит чтение термопрофиля платы.

## Использование CLI

Консольная утилита `VictusControl.exe` полезна для вызова из планировщика, профилей электропитания или пользовательских скриптов.

```powershell
# Показать текущую версию термопрофиля платы (Modern или Legacy)
.\VictusControl.exe --system

# Проверить текущий режим питания
.\VictusControl.exe --get

# Вывести флаги видеокарты (cTGP, Dynamic Boost, DState, целевая температура)
.\VictusControl.exe --gpu

# Показать обороты вентиляторов и температуры одновременно
.\VictusControl.exe --fans

# Только температуры CPU и GPU
.\VictusControl.exe --temp

# Установить конкретный профиль
.\VictusControl.exe --set eco
.\VictusControl.exe --set balanced
.\VictusControl.exe --set perf

# Переключить на следующий режим по кругу (Eco -> Balanced -> Performance -> Eco)
.\VictusControl.exe --cycle

# Управление вентиляторами: максимум, авто-кривая или ручной процент 1-100
.\VictusControl.exe --fan max
.\VictusControl.exe --fan auto
.\VictusControl.exe --fan 45

# Режим графики (Hybrid/Discrete, как Graphics Switcher в OMEN Hub);
# переключение применяется после перезагрузки
.\VictusControl.exe --gpumode
.\VictusControl.exe --gpumode discrete

# Отчёт о возможностях этой платы (что поддерживает прошивка)
.\VictusControl.exe --info

# Включить или отключить автозапуск трея
.\VictusControl.exe --autostart on
.\VictusControl.exe --autostart off
```

Коды выхода:
- `0`: Успешное выполнение команды.
- `1`: Ошибка взаимодействия с WMI или прошивкой BIOS.
- `2`: Некорректные аргументы командной строки.

## Главное окно, трей и горячие клавиши

После запуска `VictusControlTray.exe` открывается главное окно приложения (или только иконка в трее, если включена опция «Start minimized to tray»). Повторный запуск exe не создает вторую копию, а разворачивает окно уже работающего приложения.

Окно содержит:
- карточки профилей ECO / BALANCED / PERFORMANCE с описанием и индикацией активного;
- живые плитки System Vitals (CPU, GPU, Fan 1, Fan 2);
- секцию GRAPHICS MODE: Hybrid (авто) ↔ Discrete (только дискретка), как Graphics Switcher в OMEN Hub; применяется после перезагрузки;
- панель Fan Control: Auto / Max 100% / Manual с ползунком процента;
- настройки: OSD, watchdog, автозапуск, старт свёрнутым, поведение кнопки закрытия.

Секции, не поддержанные прошивкой конкретной платы, скрываются автоматически.

Кнопка закрытия окна по умолчанию сворачивает приложение в трей. Полный выход — через «Exit» в меню иконки трея.

Иконка в трее отображает статус цветовым маркером:
- Зеленый: Экономичный режим.
- Синий: Сбалансированный режим.
- Красный: Режим максимальной производительности.
- Серый: Состояние ожидания или инициализации.

Действия:
- **Двойной клик по иконке**: открытие главного окна.
- **Одиночный правый клик**: быстрое меню выбора профиля, max fan и выход.
- **Нажатие Fn+P или клавиши OMEN**: моментальное циклическое переключение с выводом экранного OSD.
- **Нажатие Ctrl+Shift+P**: альтернативная смена режима.

## Автозапуск и работа от батареи

Обычное добавление приложения в реестр автозапуска Windows вызывает окно UAC при каждом входе в систему. Чтобы избежать этого, VictusControl настраивает задачу в Task Scheduler:

1. Задача создается с правами `HIGHEST` и триггером `ONLOGON`.
2. В конфигурацию задачи вносятся изменения, снимающие стандартные ограничения Windows:
   - `<DisallowStartIfOnBatteries>` устанавливается в `false`.
   - `<StopIfGoingOnBatteries>` устанавливается в `false`.

В результате утилита стартует без диалогов UAC независимо от того, подключен ноутбук к розетке или работает от батареи.

## Безопасность и ядро Windows

Многие сторонние утилиты для ноутбуков используют уязвимый драйвер `WinRing0.sys` для прямой записи в порты Embedded Controller. В современных версиях Windows 11 этот драйвер заблокирован механизмом защиты памяти (HVCI / Memory Integrity).

VictusControl работает исключительно через документированный программный интерфейс `Microsoft.Management.Infrastructure` (CIM / WMI), обращаясь к системному классу `hpqBIntM` драйвера `acpi.sys`. Это дает:
- Полную совместимость с включенной изоляцией ядра.
- Отсутствие синих экранов (BSOD) из-за нестабильных низкоуровневых драйверов.
- Безопасную работу с памятью управляемого кода C#.

## Сборка из исходников

Для самостоятельной сборки потребуется [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0).

```bash
# Клонирование репозитория
git clone https://github.com/hexdm09/VictusControl.git
cd VictusControl

# Запуск автоматических тестов
dotnet test VictusControl.sln -c Release

# Сборка консольной версии в один файл
dotnet publish src/VictusControl.Cli -c Release -o dist

# Сборка приложения в трее
dotnet publish src/VictusControl.App -c Release -o dist
```

Готовые исполняемые файлы будут находиться в каталоге `dist/`.
